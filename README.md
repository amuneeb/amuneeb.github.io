# amuneeb.github.io

Personal portfolio of **Muneeb Abbasi** — Principal AI Engineer.

Live at **[amuneeb.github.io](https://amuneeb.github.io)**.

## Stack

- [Next.js](https://nextjs.org) (App Router, static export)
- [Tailwind CSS](https://tailwindcss.com) v4
- Deployed to GitHub Pages via GitHub Actions on every push to `main`

## Development

```bash
npm install
npm run dev
```

Site content (intro, projects, experience, skills) lives in [`src/data/profile.ts`](src/data/profile.ts).

## Build

```bash
npm run build
```

Outputs a fully static site to `out/`.
